1. Высота карточек «Параметров»: 69,7 / 66 (spec) → 63, однострочные 61–62 (пакет 3) → **63 у всех**, высоту не менять (пакет 5, макет v3).

3. Между группами: 28 при обычном заголовке → **56 от карточки до карточки с заголовком**, заголовок **14/600** (пакеты 3, 5).
4. Шаг радиокнопок: 40 (пакет 4) → 32–36 (пакет 5) → **34** (v3).

6. Тело «Сведений»: фон окна `#F3F3F3` (spec, пакет 2, compare) → **продолжение карточки** (пакет 3, v3). Скругление «4 по внешним углам» (пакет 3) → **8, как у карточек** (v3).
7. Меню ⋯:

8. Список размеров: открывается вниз под полем (14.11) → **поверх поля, как все списки** (пакет 4, п. 9a).
