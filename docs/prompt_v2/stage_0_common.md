## Цель и платформа

- Приложение **Signature Extractor** / «Извлечение подписи»: Windows-программа, которая из фото или скана подписи делает чистые файлы PNG, SVG и DXF.
- Версия **1.0**, лицензия **GNU GPLv3**, только Windows, не кроссплатформенное.
- Минимум: **Windows 10 версии 1809 (64-bit)** и новее. 32-битные системы не поддерживаются.
- Стек: **Python 3 + CustomTkinter**. Репозиторий: https://github.com/stanislau-salavei/signature-extractor.
- Автор и копирайт в интерфейсе: `© 2026 Stanislau Salavei` (латиница, не ссылка).
- Заголовок окна, ярлык в меню «Пуск» и имя `.exe` следуют языку интерфейса: «Извлечение подписи» / `Signature Extractor`. Номер версии в заголовке окна не показывать.
- Обработка только на компьютере пользователя. В интернет программа обращается исключительно для проверки обновлений, и только если это включено в параметрах.

## Команды и git

- Пиши код только текущего этапа. Не начинай следующий, пока пользователь не примет этот и не даст команду.
- Каждый этап — в своей ветке `stage-N` и через pull request в репозитории. В `main` напрямую не коммитить и не пушить. Пользователь проверяет сборку на Windows и сливает PR сам.
- **Коммит — только по явной команде пользователя**, по одному этапу. Не пушить в GitHub, пока пользователь это не поручит.
- Замечания к этапу приходят пакетами. Исправляй только то, что в пакете, и не переделывай уже принятое. Если работа прервалась, продолжай с текущего состояния ветки (`git diff`), не начинай заново.
- Макеты, таблицу i18n и иконку не менять.
- Пользовательские строки не придумывать и не зашивать в код: только таблица i18n.

## Интерфейс и темы

### Общий принцип

- Ориентир — **родные приложения Windows 11**, а не «похоже на Fluent». Макеты v3 уже сверены с ними; если в макете чего-то нет, делай как в эталонном приложении, а не по своему вкусу:
  - страница «Параметры», плотность карточек и тёмная палитра — **Windows Terminal** (Параметры);
  - строки раскрытых карточек, значки строк и полоса прокрутки — **Блокнот** (Параметры);
  - раскрытая карточка «Сведения» и радиокнопки — **Калькулятор**;
  - флажки, выпадающие списки и поля ввода — **Параметры Windows** (Специальные возможности › Контрастные темы; Дисплей › Настраиваемое масштабирование);
  - меню ⋯ — **Диспетчер задач**;
  - зона перетаскивания на экране 1 — **Quick Share**.
- Использовать стандартные виджеты CustomTkinter плюс **один** кастомный: холст предпросмотра. Не опираться на приватные API CustomTkinter (это было условием новой архитектуры, t4s). Элементы, которые CustomTkinter не умеет рисовать как в Windows 11 (радиокнопки, флажки, тумблеры, всплывающие списки, меню), допускается собирать из стандартных виджетов и картинок состояний (см. «Сглаживание»).
- Тема: «Использовать параметры системы», «Светлая», «Тёмная». При системной теме следовать оформлению Windows и обновлять окно, если система сменила тему. При **любой** смене темы, включая переход на системную, перерисовываются **все** элементы: радиокнопки, флажки, тумблеры, поля, списки, меню, фон холстов. Ни один элемент не должен остаться в цветах прежней темы.
- Кнопка ⋯ — утверждённый вариант размера B. Плитки форматов — цветные надписи «PNG» / «SVG» / «DXF», не «ластиковые» значки.
- Дочерние окна (справка по форматам, диалоги, «О программе», «Свой цвет»): локализованный заголовок, без крупной иконки и имени приложения в хроме окна.
- Шрифт: `Segoe UI Variable Text` → `Segoe UI Variable` → `Segoe UI`. Вес 600 — полужирный (Semibold), никогда не 700; если Semibold нет, взять `Segoe UI Semibold`, а при его отсутствии — Bold.

### Заголовок окна

- Как в Windows Terminal: заголовок окна **того же цвета, что фон интерфейса**, а не акцентного цвета Windows. Через `DwmSetWindowAttribute`: `DWMWA_CAPTION_COLOR` (35) = фон окна (`#F3F3F3` светлая / `#202020` тёмная), `DWMWA_TEXT_COLOR` (36) — цвет текста темы, `DWMWA_USE_IMMERSIVE_DARK_MODE` (20) включён в тёмной. Обновлять при смене темы. На Windows 10, где этих атрибутов нет, тихо пропускать.
- В заголовке: иконка 16 × 16, локализованное имя 12 px. Кнопки окна — системные.

### Сглаживание и DPI

- **Все** скруглённые формы и линии рисуются сглаженно при 100 / 125 / 150 %: обводки и углы карточек, флажки, радиокнопки, тумблеры, рамки списков и полей, меню ⋯ и всплывающие окна. Ступенек, «восьмиугольных» колец и квадратных кружков быть не должно. Рекомендуемый способ: рисовать каждое состояние элемента в PIL с запасом 4× (`ImageDraw.rounded_rectangle` / `ellipse`) и уменьшать с `LANCZOS` в `CTkImage` / `PhotoImage`, с кэшем по размеру, теме, состоянию и масштабу; или сглаженные углы самого CustomTkinter.
- Фон под нарисованным элементом совпадает с фоном карточки, на которой он стоит: никаких светлых квадратов вокруг тумблеров, белых углов вокруг меню или серых полос под всплывающими окнами.
- Приложение объявлено **per-monitor DPI aware (v2)**, чтобы Windows не растягивала его как картинку; при переносе окна на монитор с другим масштабом интерфейс пересчитывается и остаётся чётким.

### Клавиши

Утверждено 16.11.2026, сочетания указываются в подсказках кнопок:

- в редакторе на экране 2: **Ctrl+Z** — отмена; **Ctrl+Y** и **Ctrl+Shift+Z** — повтор (в подсказке указан только Ctrl+Y); история **без ограничения шагов**, отдельно для каждого фото;
- **Ctrl+O** — «Открыть файл» (на экранах 2–3 это новая работа, с диалогом 20, если есть несохранённый результат);
- **Ctrl+S** — перейти к шагу «Экспорт», если есть готовый результат;
- **Esc** закрывает окна справки и параметров (не главное окно приложения), а также открытый список или меню;
- **Enter** в текстовом поле применяет значение, как кнопка «✓».

## Элементы управления (общие для всех экранов)

Числа — логические пиксели при 100 %. Подробности по каждой странице — в этапах; здесь то, что одинаково везде.

- **Выпадающий список (ComboBox), закрыт**: высота 32, радиус 4, отступы 0 10 0 12, текст 14 px, шеврон 14 × 14 справа, цвета по таблице токенов.
- **Выпадающий список, открыт** (35, 58, 67): **все** списки, включая список размеров на экране 3, раскрываются **поверх поля**, как в Windows 11: выбранный пункт стоит на месте поля, а само окно сдвигается вверх или вниз, чтобы не выйти за окно приложения (верх не выше 36 px от верха окна, низ не ниже 8 px от низа). Это заменяет прежнее правило «список размеров открывается вниз под полем». Окно: радиус 8, обводка 1 px, мягкая тень (светлая `0 8px 16px rgba(0,0,0,.14), 0 0 2px rgba(0,0,0,.10)`, тёмная `0 8px 16px rgba(0,0,0,.26), 0 0 2px rgba(0,0,0,.30)`), внутренние отступы 2 сверху/снизу и 4 по бокам, ширина = ширина поля + 8 (левый край на 4 px левее поля; список размеров — не уже 236). Пункт: высота 36, шаг 38, отступы 0 12, радиус 4, текст 14 px. Выбранный пункт: обычный цвет текста, лёгкая заливка (`rgba(0,0,0,.055)` / `rgba(255,255,255,.06)`) и вертикальная акцентная черта 3 × 16 с радиусом 2 у левого края. Наведение — та же заливка со скруглением 4. Высота окна не больше 392 px; длиннее — прокрутка с тонкой полосой. Без серых полос и двойной кромки внизу.
- **Текстовое поле (TextBox)** (66): высота 32, радиус 4, отступы 0 4 0 11, текст 14 px. В покое — тонкая обводка 1 px и более тёмная нижняя кромка 1 px. В фокусе — та же обводка плюс **акцентная линия 2 px только снизу**, не синяя рамка целиком, без артефактов в углах; в тёмной теме фон поля в фокусе темнее (`#1F1F1F`). Внутри справа — кнопка «×» 24 × 24 (радиус 4, вторичный цвет), видна, пока в поле есть текст и фокус; очищает поле. Справа от поля через 8 px — отдельная квадратная вторичная кнопка **«✓»** 36 × 32, применяет значение; Enter делает то же. Подсказки при наведении (утверждено 16.11.2026), в стиле подсказок Windows 11 и тем же общим компонентом, что остальные подсказки приложения (задержка, вид, без точки в конце): «✓» — «Применить» / `Apply` (`common.textbox.apply.tooltip`), «×» — «Очистить» / `Clear` (`common.textbox.clear.tooltip`).

- **Тумблер**: 40 × 20, радиус 10, обводка 1 px; один кружок 12 × 12 (слева 4, сверху 3 в «Откл.»; слева 22 в «Вкл.»), пустая дорожка без второго кружка. «Вкл.»: заливка и обводка акцентом, кружок белый (светлая) / чёрный (тёмная). Подпись «Вкл.» / «Откл.» 14 px слева от тумблера, зазор 12 px, текст по центру тумблера.
- **Радиокнопка** (64): круг 20 px. Выбрана — толстое акцентное кольцо (заливка акцентом с центральной точкой 10 px: белой в светлой, чёрной в тёмной). Не выбрана — кольцо 1 px и светлая заливка (токены), при наведении кольцо темнеет. Подпись 14 px основного цвета, в 8 px от круга. Шаг строк **34 px**.
- **Флажок** (65): скруглённый квадрат 20 px, радиус 4. Отмечен — заливка акцентом и галочка (белая в светлой, чёрная в тёмной). Не отмечен — светлая заливка и серое кольцо 1 px (токены).
- **Меню** (19, 36, 52, 61): как меню Диспетчера задач — см. этап 1, раздел «Меню ⋯». Те же цвета, радиус и тень у всех контекстных меню.
- **Полоса прокрутки** (Параметры, справка, списки, окно 21): как в Блокноте. В покое — тонкая скруглённая линия 2 px, без стрелок и дорожки, около 4 px от правого края области. При наведении на её зону плавно расширяется до ~6 px со скруглёнными концами, появляются маленькие стрелки сверху и снизу и едва заметная дорожка; примерно через 1 с после ухода мыши снова сужается до линии. Ползунок перетаскивается левой кнопкой (страница листается пропорционально), щелчок по дорожке листает на страницу, стрелки — на шаг, колесо работает над любым местом страницы. Полоса **накладывается** на содержимое и не отнимает ширину у карточек. Длина и положение ползунка пропорциональны содержимому.

## Размеры окна и масштабирование

- По умолчанию окно открывается в **1280 × 800** логических пикселей.
- Минимум **1024 × 680**. Меньше нельзя.
- Размеры на макетах заданы в логических пикселях. При системном масштабе 100 % стандартный кадр — 1280 × 800; 2K-кадры — развёрнутое окно на мониторе 2560 × 1440 при масштабе 125 % (примерно 2048 × 1150 логических). Приложение должно корректно учитывать DPI Windows (per-monitor, см. «Сглаживание и DPI»).
- При изменении размера и при развороте:
  - правые колонки настроек на экранах 2 и 3 фиксированной ширины, всё лишнее место уходит предпросмотру;
  - в ленте пакета помещается больше миниатюр **того же размера**, миниатюры не укрупняются;
  - параметры и справка ограничены шириной около **1000 px** и стоят по центру;
  - переключатель шагов (степпер) остаётся по центру, нижняя панель кнопок прижата к краям.
- На минимальной ширине «Сбросить к авто» и «По размеру» становятся **только иконками с подсказкой** (экраны 53, 54, 57).

## Архитектура

Из принятой концепции нового UI (t4s):

- Строгое разделение: **ядро без UI** (загрузка, маска, AI, экспорт), **контроллер состояния**, экраны в `ui/pages/`, общие виджеты в `ui/widgets/` (там же — общие Win11-элементы: радиокнопка, флажок, тумблер, TextBox с «×» и «✓», всплывающий список, меню, полоса прокрутки, рендер сглаженных состояний).
- Один фоновый воркер с очередью задач и отменой устаревших результатов. Окно никогда не «замирает», ожидая обработку или экспорт.
- Логирование вместо голого `except: pass`.

Точные имена пакетов в репозитории не утверждались; держись этой раскладки или той, что уже принята в ветке этапа 1.

## Файл настроек и что в нём хранить

- Путь: `%APPDATA%\Signature Extractor\settings.json` (обычно `C:\Users\<пользователь>\AppData\Roaming\Signature Extractor\settings.json`). Формат — **JSON**.
- Запись **атомарная**: сначала временный файл в той же папке, затем замена (`os.replace` или эквивалент), чтобы при сбое не оставался обрезанный документ.
- Обновление установщиком и удаление приложения **этот файл не трогают** (свои шаблоны и свои цвета сохраняются и после удаления программы).
- Настройки переживают перезапуск программы.
- Хранить как минимум:
  - тему и язык;
  - «AI-поиск подписи по умолчанию»;
  - «Ускорение на видеокарте»;
  - форматы по умолчанию, размер по умолчанию, «Поле рамки при обрезке» (число в миллиметрах), цвет по умолчанию, разрешение PNG;
  - папку сохранения, шаблон имени, режим «Если файл уже есть»;
  - «Проверять обновления при запуске»;
  - список своих шаблонов размера и своих цветов;
  - последние настройки экспорта, которые должны сохраниться после «Готово» (форматы, размер, разрешение).
- Не заявлять в настройках имя AI-модели и не давать её удалять: модель **встроена** в приложение, пользователь её не скачивает (t34u, t36u).
