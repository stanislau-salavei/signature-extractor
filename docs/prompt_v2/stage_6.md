# Этап 6. Установщик и релиз

Сначала прочитай и соблюдай `stage_0_common.md`. Этапы 1–5 должны быть приняты, приложение собирается в распространяемый вид. Работа — в ветке `stage-6` и отдельном PR. Коммит и публикация релиза — только по команде пользователя.

## Цель

Per-user установщик Inno Setup без прав администратора, ярлыки, запись в «Установленные приложения», публикация GitHub Release с установщиком и SHA-256, чтобы встроенная проверка обновлений из этапа 5 работала.

## Экраны

Отдельных макетов установщика нет. Имя, иконка и лицензия должны совпадать с приложением. Иконка: `/workspace/mockups/final/icon/app.ico`.

## Сборка приложения

- Приложение упаковывается **PyInstaller в режиме onedir** (папка с exe и зависимостями, не один огромный файл).
- Эту папку Inno Setup упаковывает в установщик с именем **`SignatureExtractor-1.0-setup.exe`** (для следующих версий — `SignatureExtractor-<ver>-setup.exe`).
- Подпись кода (Authenticode) **не делаем в 1.0**; она остаётся необязательной на будущее.
- В рантайме нет сетевых зависимостей сверх проверки обновлений.

## Установщик

- Технология: **Inno Setup**.
- Только **для текущего пользователя**, без запроса прав администратора и без окна UAC — и при первой установке, и при обновлении.
- Каталог установки: `%LOCALAPPDATA%\Programs\Signature Extractor` (обычно `C:\Users\<пользователь>\AppData\Local\Programs\Signature Extractor`).
- Ярлык в меню «Пуск» создаётся **всегда**. Подпись ярлыка следует языку: «Извлечение подписи» / `Signature Extractor`.
- Ярлык на рабочем столе — **по галочке, которая по умолчанию снята**.
- Приложение появляется в списке «Установленные приложения» (Параметры Windows), оттуда его можно удалить.
- Установщик **отказывается** работать на системе старше Windows 10 1809 и на 32-bit, с понятным сообщением.
- Языки установщика: **русский и английский**. При старте выбирается язык Windows; если его нет среди этих двух — **английский**. Язык, на котором прошла установка, становится **начальным языком интерфейса приложения** при первом запуске; позже его можно сменить в параметрах.
- Передача языка в приложение (утверждено 16.11.2026) — **только аргументом запуска** `--installer-language ru|en` через точку входа из этапа 1 (`read_installer_language()`). Файл `installer_language.txt` установщик **не создаёт**, переменных окружения не задаёт. Аргумент передаётся при запуске программы в конце установки; чтобы язык подхватился и при первом запуске из «Пуска», тот же аргумент записан в параметры ярлыков (в «Пуск» и на рабочем столе). Приложение учитывает его только при первом запуске без `settings.json`, поэтому дальше и после обновления поверх язык пользователя не меняется.
- Обновление ставится **поверх** прежней версии в тот же каталог. Если приложение запущено, установщик **просит его закрыть**. Файл `%APPDATA%\Signature Extractor\settings.json` при обновлении и при удалении **не трогать**.
- В дистрибутив входят: сборка onedir, встроенная модель IS-Net, текст GNU GPLv3, иконка, таблица строк (или уже упакованные ресурсы).
- SHA-256 установщика **считается при сборке** и публикуется вместе с ним (см. ниже).

## Релиз на GitHub

- Репозиторий: https://github.com/stanislau-salavei/signature-extractor.
- Публикация — **только по команде пользователя**. Тег вида `v1.0.0`; версия приложения **1.0**.
- В файлах релиза рядом: `SignatureExtractor-<ver>-setup.exe` и **`SignatureExtractor-<ver>-setup.exe.sha256`**. Та же контрольная сумма дублируется в тексте заметок релиза. Приложение на этапе 5 скачивает оба и сверяет сумму до запуска установщика.
- Описание релиза понадобится ссылке «Заметки о выпуске». Не выдумывай текст заметок без пользователя.
- После публикации «Проверить сейчас» в сборке 1.0 не должен предлагать обновление на саму себя; при следующем теге — должен показать диалог 32, скачать установщик, сверить SHA-256, при несовпадении показать ошибку и удалить файл, при совпадении запустить установщик без UAC и открыть новую версию.
