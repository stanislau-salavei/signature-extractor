## Извлечение подписи 1.0.1

Программа выглядит и работает так же, как 1.0, но стала легче и быстрее; обновлён установщик. Результаты экспорта (PNG, SVG, DXF) не изменились.

**Что изменилось**
- Установщик стал меньше: 46,0 МБ вместо 60,4 МБ; установленная программа занимает 161,5 МБ вместо 238,6 МБ.
- Быстрее открываются и обрабатываются фото, быстрее перерисовываются экраны.
- Внутренняя переработка кода: проще поддерживать, больше автоматических проверок.
- Новый вид установщика: страница приветствия с кратким описанием программы и ссылкой на лицензию, значок и название программы на страницах, на странице «Всё готово к установке» показана папка установки, на последней странице — флажок «Запустить программу».
- В английском установщике и в списке «Установленные приложения» (при установке на английском) программа называется Signature Extractor.
- При удалении программы можно сразу удалить и настройки: флажок «Удалить настройки» (включён по умолчанию) удаляет параметры, свои шаблоны размеров и цвета и журнал работы. Сохранённые подписи не удаляются. При обновлении настройки сохраняются.
- В самой программе видимых изменений нет, кроме номера версии.

**Установка**
- Скачайте `SignatureExtractor-1.0.1-setup.exe` ниже и запустите. Права администратора не нужны, программа ставится только для вашей учётной записи.
- Нужна Windows 10 версии 1809 (64-bit) или новее.
- Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».
- Контрольная сумма SHA-256 — в файле `SignatureExtractor-1.0.1-setup.exe.sha256` и в конце этих заметок.

## Signature Extractor 1.0.1

The program looks and works the same as 1.0, but it is lighter and faster, and the installer has been updated. Export results (PNG, SVG, DXF) are unchanged.

**What's changed**
- Smaller installer: 46.0 MB instead of 60.4 MB; the installed program takes 161.5 MB instead of 238.6 MB.
- Photos open and are processed faster; screens redraw faster.
- Internal code cleanup: easier to maintain, more automated checks.
- A refreshed installer: a welcome page with a short description of the program and a link to the license, the program icon and name on the pages, the install folder on the "Ready to Install" page, and a "Launch the program" check box on the last page.
- The English installer and the "Installed apps" list (for English installs) name the program Signature Extractor.
- Uninstalling can also remove the settings: the "Remove settings" check box (on by default) deletes the preferences, your own size templates and colours, and the log. Saved signatures are not deleted. Updates keep the settings.
- No visible changes in the program itself apart from the version number.

**Installation**
- Download `SignatureExtractor-1.0.1-setup.exe` below and run it. No administrator rights are needed; the program is installed for your account only.
- Requires Windows 10 version 1809 (64-bit) or later.
- The installer is not digitally signed, so Windows SmartScreen may show "Windows protected your PC". Click "More info" → "Run anyway".
- The SHA-256 checksum is in `SignatureExtractor-1.0.1-setup.exe.sha256` and at the end of these notes.
