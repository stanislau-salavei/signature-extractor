## Извлечение подписи 1.0.1

Внутренний выпуск: программа выглядит и работает так же, как 1.0, но стала легче и быстрее. Результаты экспорта (PNG, SVG, DXF) не изменились.

**Что изменилось**
- Установщик стал меньше: 44,7 МБ вместо 60,4 МБ; установленная программа занимает 161,5 МБ вместо 238,6 МБ.
- Быстрее открываются и обрабатываются фото, быстрее перерисовываются экраны.
- Внутренняя переработка кода: проще поддерживать, больше автоматических проверок.
- Видимых изменений нет, кроме номера версии.

**Установка**
- Скачайте `SignatureExtractor-1.0.1-setup.exe` ниже и запустите. Права администратора не нужны, программа ставится только для вашей учётной записи.
- Нужна Windows 10 версии 1809 (64-bit) или новее.
- Установщик не подписан цифровой подписью, поэтому Windows SmartScreen может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».
- Контрольная сумма SHA-256 — в файле `SignatureExtractor-1.0.1-setup.exe.sha256` и в конце этих заметок.

## Signature Extractor 1.0.1

A maintenance release: the program looks and works the same as 1.0, but it is lighter and faster. Export results (PNG, SVG, DXF) are unchanged.

**What's changed**
- Smaller installer: 44.7 MB instead of 60.4 MB; the installed program takes 161.5 MB instead of 238.6 MB.
- Photos open and are processed faster; screens redraw faster.
- Internal code cleanup: easier to maintain, more automated checks.
- No visible changes apart from the version number.

**Installation**
- Download `SignatureExtractor-1.0.1-setup.exe` below and run it. No administrator rights are needed; the program is installed for your account only.
- Requires Windows 10 version 1809 (64-bit) or later.
- The installer is not digitally signed, so Windows SmartScreen may show "Windows protected your PC". Click "More info" → "Run anyway".
- The SHA-256 checksum is in `SignatureExtractor-1.0.1-setup.exe.sha256` and at the end of these notes.
